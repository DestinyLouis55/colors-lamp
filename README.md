Description of the COLORS application:
The COLORS application an application that allows users to log in and view colors in their collection by searching for the color specifically or searching for colors that contain a specific letter. Users can also add colors to their collection. This application was created during the COP4331 LAMP Stack Lab.

Technologies used:
JavaScript, LAMPStack, PHP, HTML, MySQL, FileZilla, PuTTY, Postman

High-level setup instructions
1. Create LAMP server: Use digitalocean to create a LAMP Droplet using Ubuntu, complete all requried steps.
2. Configure MySQL: create database by creating a users and colors table
3. Configure PHP API files: configure the login.php, addcolor.php, searchcolors.php 
4. Upload files into directory: using FileZilla, add the files to web directory
5. Test API: using Postman, test the PHP files
6. Access App: use the domain name set to load to page, log in using the username and password set

How to run and access the applicaiton
1. Open the application and login using the username and password set
2. Using the search field, type the color or letter of choice, then press search color
3. Using the add field, type the color you want to add then press add color
4. Log out using the log out button once done

Limitations
- Must use mysql database
- Can not remove colors
